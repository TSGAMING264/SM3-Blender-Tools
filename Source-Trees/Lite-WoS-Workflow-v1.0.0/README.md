# Lite WoS Workflow v1.0.0

This source tree keeps the smaller Lite toolkit separate from the Full workflow and from the original repository source.

## Add-ons

- [`SM3-WoS-Lite-Blender-Toolkit/`](SM3-WoS-Lite-Blender-Toolkit/) — SM3 WoS Lite Blender Toolkit v1.0.0. Its add-on metadata declares Blender 4.1.0 or newer.
- [`Material-Combiner-Companion/`](Material-Combiner-Companion/) — the companion supplied with the Lite handoff. It is byte-for-byte identical to the companion in the Full tree and is retained here so this tree is self-contained.

Install the add-ons separately. Begin with [`SM3-WoS-Lite-Blender-Toolkit/README.md`](SM3-WoS-Lite-Blender-Toolkit/README.md) and its [`MATERIAL_ROUTING.txt`](SM3-WoS-Lite-Blender-Toolkit/MATERIAL_ROUTING.txt).

The imported source files are preserved from the supplied archives. Repository-authored organization notes live only in this tree-level README.
