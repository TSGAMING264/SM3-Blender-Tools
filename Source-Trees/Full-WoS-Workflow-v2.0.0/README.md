# Full WoS Workflow Clone v2.0.0

This source tree keeps the Full workflow and its Material Combiner companion together without modifying the original repository source tree.

## Add-ons

- [`SM3-Blender-Toolkit/`](SM3-Blender-Toolkit/) — SM3 WoS Workflow Clone v2.0.0. Requires Blender 4.5.0 or newer according to its extension manifest.
- [`Material-Combiner-Companion/`](Material-Combiner-Companion/) — separate atlas-combiner companion. Its supplied manifest reports version 2.3.0 and Blender 4.2.0 or newer; the source archive was named as the v2.0.0 companion.

Install the two add-ons separately. Start with [`SM3-Blender-Toolkit/START_HERE_WOS_CLONE.txt`](SM3-Blender-Toolkit/START_HERE_WOS_CLONE.txt), then read the toolkit and companion READMEs before using the workflow.

The imported source files are preserved from the supplied archives. Repository-authored organization notes live only in this tree-level README.
