SM3 MATERIAL COMBINER TOOLKIT v1.0.0 - BLENDER 4.5/5.x INSTALL

1. Do NOT unzip the release ZIP.
2. Blender -> Edit -> Preferences -> Add-ons / Extensions -> Install from Disk.
3. Choose SM3-Material-Combiner-Toolkit-v1.0.0-BLENDER5.zip.
4. Enable "SM3 Material Combiner Toolkit" only when material research is needed.
5. Open the 3D View N-panel -> SM3 Materials.
